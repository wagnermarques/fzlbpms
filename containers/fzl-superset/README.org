* fzl-superset

Apache Superset BI/dashboard service.

- ~superset-db~: dedicated Postgres instance for Superset metadata (charts, dashboards, users).
- ~superset-redis~: dedicated Redis instance for caching and the async query/Celery results backend.
- ~superset-init~: one-shot container (mirrors ~moodle-installer~) that runs
  ~superset db upgrade~, creates the admin user, and runs ~superset init~. Safe to re-run.
- ~fzl-superset~: the webserver, started after ~superset-init~ completes successfully.

Data persists in ~superset-db-data/~ (Postgres) and ~redis-data/~ (Redis), both gitignored.
