* Summary

- The repository has *no license yet* (no LICENSE/COPYING file, no license
  headers, GitHub shows none).
- Nothing found blocks a GNU license, *as long as it is version 3*
  (GPL-3.0-or-later or AGPL-3.0-or-later).
- *Recommended: AGPL-3.0-or-later* — fzlbpms runs as a web service
  (fzlbpms.com.br), and AGPL makes hosted modified versions share their source.
  GPL-3.0-or-later is fine too if the network clause is not wanted.
- Before or together with the license, fix the items in "Pending actions".

* Why version 3 (not GPL-2.0)

- Much of the stack is Apache-2.0 (Camel, Karaf, Keycloak libs, Tauri, bollard).
  Apache-2.0 combines with GPL-3.0/AGPL-3.0, but *not* with GPL-2.0-only.
- ~bin/moodle/*.php~ run inside Moodle (GPL-3.0-or-later), so they must be
  under a GPLv3-compatible license. AGPL-3.0 and GPL-3.0 both are (GPLv3 §13).

* Pending actions

** 1. License violation today: bpmn.io watermark hidden (fix regardless of license)

~bpmn-js~ is MIT plus one condition: the bpmn.io watermark in rendered diagrams
must stay visible and its code unchanged. The Theia BPMN plugin hides it:

- ~src-projects/fzl-theia-plugins/theia-plugin-bpmn-editor/src/webview/style.css~ line 40:
  #+begin_src css
  .bjs-powered-by {
      display: none;
  }
  #+end_src
- also present in the built bundles:
  - ~src-projects/fzl-theia-plugins/theia-plugin-bpmn-editor/media/bpmn-editor.css~
  - ~src-projects/fzl-theia-plugins-dist/theia-plugin-bpmn-editor/media/bpmn-editor.css~

Fix: delete the rule from ~style.css~, rebuild the plugin (regenerates
~media/*~ and the ~.vsix~), and copy the result to ~fzl-theia-plugins-dist~.
Check ~fzlbpmsadmin-web~ (also uses bpmn-js) keeps the watermark visible too.

With the watermark kept, bpmn-js generally fits under GPLv3 §7(b) (terms
requiring preservation of author attributions); the FSF has not reviewed this
license, so it remains a gray area worth knowing about.
