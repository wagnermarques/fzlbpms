## Executive Summary

**fzlbpms** (FZL Business Process Management System) is an enterprise-grade, containerized application and workflow platform designed to orchestrate business processes, educational services, and application integrations. Built around an **Apache Karaf (OSGi) + Apache Camel** integration backbone and a **Flowable BPM** workflow engine, the platform integrates Single Sign-On (SSO via **Keycloak**), interactive human tasks (**Orbeon Forms**), learning management (**Moodle**), development tooling (**Eclipse Theia Web IDE**, **Nexus**, **GitLab**), and modern web/desktop administration frontends (**Tauri v2** + **Angular**).

This directory (`./gemini-cli/`) houses the complete architectural, infrastructure, integration, security, and operational breakdown of the project.
